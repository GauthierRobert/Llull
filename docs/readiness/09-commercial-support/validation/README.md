# 09 COM — Validation plan

Cases prove that an office can **license llull offline, read its help in its language, get support, and meet its legal duties**
(PRL 4 "Adoptable", [`../../VALIDATION.md`](../../VALIDATION.md)). Machine index: [`expected_results.json`](expected_results.json)
(schema [`../../vc.schema.json`](../../vc.schema.json)). Sources and grades: [`sources.md`](sources.md).

Grades: **A** primary source read or measured in llull; **B** one secondary extract; **C** located, not confirmed; **target** =
a budget or behaviour set by this spec (gating). Machine profile: `ref-win11` unless stated; `install-vm` cases run on the pack 05
clean-VM images with the network adapter **disabled** and an outbound firewall log enabled. `review` cases pass only with a stored
record under `records/` (VALIDATION.md §5): legal reviews are done by counsel (`role: legal-counsel`), never by an agent.

Readiness level: the pack default is **PRL 4**. Cases that are prerequisites of earlier levels say so (signed updates and zero
network are install concerns, PRL 1; the document compatibility promise and read-only fallback are trust concerns, PRL 2).

## Use cases

1. **UC-1 Buy and activate offline.** IT activates seats by file exchange on air-gapped PCs; a laptop borrows a floating seat (FR-01..10).
2. **UC-2 Never locked out.** Whatever happens to the licence or the clock, documents open, save and export (FR-03, 06, 07).
3. **UC-3 Upgrade with confidence.** SemVer, deprecations, compatibility, support end date, signed offline updates, SBOM (FR-11..16).
4. **UC-4 Get help.** Support bundle reviewed by the user, intake, SLA, security reports, CRA reporting (FR-17..21).
5. **UC-5 Learn and look up.** Generated reference for every command, Diátaxis docs, F1, offline (FR-22..25).
6. **UC-6 Work in FR / NL / DE.** Translated UI, decimal comma, untranslated codes and JSON (FR-26..30).
7. **UC-7 Legal and accessibility.** EULA, disclaimer, privacy, CRA file, user information, data removal, EN 301 549 (FR-31..38).
8. **UC-8 Train.** Curriculum and auto-graded exam (FR-39, 40).
