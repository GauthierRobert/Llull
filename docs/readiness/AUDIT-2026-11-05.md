# Flaw and completeness audit — 2026-11-05

Owner request: "Analyse what are all the flaws in the current app, what feature can be considered incomplete or not
finished. List all, mark them as next priority, and search deeply to create the better specs and validation to make them
flawless."

Method:
- five read-only audits of the code at main `00d5326f5`: data safety and core, UI and interaction, install / perf / exchange,
  engineering domains, debt and security;
- each finding has file:line evidence. Every S1 / S2 claim used below to set a priority was re-read in the code by the
  coordinator; corrections are marked *(re-verified)*;
- nothing was run (no tests, no app): the statuses are code reads, not measurements.

Outputs of this audit:
1. **this register**: every flaw, its severity, its priority and the spec that closes it;
2. **new pack [`10-result-integrity/`](10-result-integrity/)** (gap `INT`, PRL 2): the one class no existing pack covered, the
   silent wrong answer. 14 FRs, 16 TRs, 27 VCs (25 gating), each VC written to fail on today's code;
3. **spec corrections** to packs 02–09 (§4): what the 2026-10-28 packs got wrong or no longer match;
4. **board and documentation drift** (§5).

## 1. Headline

llull has very deep command capability. The production gate passes four office jobs, and plant, design, CAE and aero are
largely built. What is unfinished is concentrated in three places:

1. **Results that can be silently wrong** (P0). In the command engine, zod parsing is done and then discarded. Steel grade,
   thickness, bolt class and road speed are replaced without a word. FE margins are trusted on any mesh. A missing exact
   kernel answers with meshes. Locked layers bind the UI only. Test lanes go green without the tools they test. None of it
   is in any pack; it is now pack 10 INT.
2. **The professional product around the commands** (P1). The nine readiness packs (2026-10-28) are still unbuilt, and
   **none of them is on the board**. All work since then went to plant / visualisation milestones. So data safety (single
   autosave slot, no file lock, no backend restart), install (no `llull doctor`, CLI shim without the bundled runtime,
   unsigned, no updater) and the Electron e2e harness are all still open.
3. **Daily drafting and exchange depth** (P2): no typed coordinates, command line, grips or snap toggles. Grid snap can't be
   turned off. No 2D DXF / SVG / PDF export of plain drawings. The generic command form cannot pick points or edges.

The remaining open items (P3) are breadth: 11 physics packs that are spec-only or partial, CFD-M3+, PST-M5a, VIS-M8,
design 08 ASC, and refusals by name in blends.

### Status 2026-11-06: P0 closed (merge `fix/p0-integration` → main 69590eec3)

- **Desktop suite:** green.
- **Static checks:** typecheck, arch, deadcode, lint, format, CSS and native all green.

Fixed vs. the register:
- **A-01:** the parsed params reach `run`. `tolerant()` keeps the raw value, and an own `__proto__` key is refused.
- **A-02..A-05:** steel strength comes from grade + thickness, and bolts from class + exact size. Road speeds are checked against the table's domain. Refused rows never count as utilisations, and `design_portal_frames` never up-sizes a refused member.
- **A-06:** FE mesh adequacy is measured in volume-based element layers. It gates margins, fatigue, distortion and `check_analysis`.
- **A-07:** every kernel-consuming command reports provenance, covered by a static contract scan. Nested calls propagate it, and the CLI, `/health` and UI warn.
- **A-08..A-11:** recovery is per-document slots with a hold → load → bind sequence. Lock files, content-hashed save conflicts, backend supervision, kept offline edits and a visible autosave failure state are in.
- **A-12:** locked layers are enforced in `execute`, and moving an entity into a locked layer is refused too.
- **A-13:** `LLULL_REQUIRE_TOOLS` lanes are in, plus the CI mapping.
- **A-14:** `verify_release` reports `partial` / `fail`.
- **A-15:** STEP names are Part-21 encoded through placeholders.
- **Also closed:** B-13 (token required, no default origin) and B-14 (zip / XML caps). B-22 is partly closed: FEA mapping fallback recorded, renderer out-of-sync banner shown.

- **Untested:**

## 4. Spec corrections to the existing readiness packs

### 4.1 04 DSF
- **Partly stale.** Atomic save + `.bak` (SC-D1) and a crash-report folder (`desktop/src/crashes.ts`, SC-D3) are built.
- **Missing.** Add **FR-DSF-23 (MUST)**: edits made while the backend was down are never discarded on reconnect. They are kept as a
  recoverable copy and offered beside the backend state. Today `REPLACED_LOCAL_EDITS` drops them (A-10).
- **Missing.** Add **FR-DSF-24 (SHOULD)**: a command can carry `expectedSeq`. When another client changed the touched entities since
  that seq, the result is `DSF_EDIT_CONFLICT` (B-12).
- **Missing.** Name `llull --doc` as its own writer path, not through the backend, in G3 / FR-DSF-14. It is the root cause of the
  lock gap.
- **Untestable as written.** Define *acknowledged* as "the command result returned to the caller, or the `/live` `command`
  event emitted". Define the power-loss fault model: unsynced writes are dropped and unsynced directory entries reordered
  (VC-DSF-06 already sketches it). Fix N ≥ 100 runs and "0 corrupt files" for every kill case.
- **Moved to INT.** Parsed params (ENG-11) and layer locks are not data-safety items.

### 4.2 05 INS
- **Stale.** Gap "llull declares no licence": llull is **GPL-3.0-or-later + commercial licence** (`LICENSE`, `package.json`,
  `docs/decisions/LIC1-license.md`, commit `6be710aa9`). README decision D1 is resolved.
- **Make it a requirement.** `cadquery>=2.4` unpinned is a fact today, not a future risk. Requirement: a hash-pinned lock file
  (`requirements.lock`, `pip --require-hashes`) for the bundled CPython.
- **Gap in the smoke test.** The build smoke test must run **every** native binary with a clean PATH (System32 only), not just
  `llull-mesh` (B-03). Add it to FR-INS-05's verification.
- **Overlap to state.** FR-INS-06 (kernel never falls back silently) covers install time. INT FR-07 adds per-result provenance.
  Cross-reference both.
