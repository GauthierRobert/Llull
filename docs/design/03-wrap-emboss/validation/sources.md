# WRP — sources (all accessed 2026-10-22)

Ids are the `[Rn]` of FUNCTIONAL_SPEC §11. Access method: **DL** = page / file read in full (WebFetch, `curl`, GitHub API; content
inspected, hashes computed where a file was used); **SR** = search-engine extract only (the page is JavaScript-rendered or behind a
login, so only the extract's statements are used); **LOC** = located, content not read. Grades as `docs/plant/TEMPLATE.md`: **A**
primary source read, reference code run, or ≥ 2 independent sources agree; **B** one secondary extract; **C** located, numbers not
confirmed. Only grade-A values and closed forms gate pass / fail; no expected value in this pack is quoted from a vendor page — all
numeric expectations are derived analytically or measured on the pinned font.

## Derivations used instead of sources (grade A by construction + numeric cross-check)

| Topic                                      | Formula                                            | Check                                                                                   |
| ------------------------------------------ | -------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Cylinder / cone development is an isometry | K = 0; chart (r·θ, z); cone chart (s, θ·sin α)     | dense-sampling lengths, residual ≤ 2e-7 (`cylinder_wrap.json`, `cone_development.json`) |
| Projection length                          | 2r·asin(w/2r)                                      | dense sampling (`projection_vs_wrap.json`)                                              |
| Sphere exponential map                     | strain sin(a/R)/(a/R) − 1, area 2πR²(1 − cos(a/R)) | numeric boundary length (`sphere_geodesic_wrap.json`)                                   |
| Emboss volume                              | Steiner: dV = (1 + 2Hn + Kn²) dA dn                | direct annulus, Pappus, Gauss–Legendre quadrature (`emboss_volumes.json`)               |
| Pull walls                                 | ∫ √(R² − y²) dy = (y√(R² − y²) + R² asin(y/R))/2   | quadrature (`pull_and_geodesic.json`)                                                   |
| Glyph area                                 | ∮(x dy − y dx)/2 with the quadratic closed form    | nonzero scanline fill (`font_firasans_glyphs.json`)                                     |
