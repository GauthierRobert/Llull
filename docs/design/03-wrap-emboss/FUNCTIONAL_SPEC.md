# WRP — Curves and features on curved faces, 3D text — Functional specification

Gap id: **WRP** · Folder: `docs/design/03-wrap-emboss/` · Status: specification (2026-10-22), nothing built ·
Track: "design anything" freeform specs (owner request 2026-10-22) · Neighbours: **01 DEF** (body deformation: bend / flow, CATIA
"Wrap Curve" surface deformation), **02 SWG** (helical sweep, used by a modeled knurl), **04 DIR** (UI gestures for placing a wrap),
**06 BLD** (fillets on emboss edges), **07 MSH** (mesh-only emboss / displacement on scans).

---

## 1. Summary

Product designers put things **on** curved faces all the time: a brand name raised on a bottle, a serial number engraved on a shaft,
a scale wrapped around a dial, a grip pattern on a knob, a parting line split on a moulded housing, a label area on a cone. In every
mainstream CAD this is one feature (SOLIDWORKS _Wrap_ emboss / deboss / scribe [R1] [R2], Fusion _Emboss_ [R4], Onshape _Wrap_ [R5],
Rhino _ApplyCrv_ / _FlowAlongSrf_ [R6] [R7], Creo _Wrap_ datum curve [R13]). llull today has the pieces but not the feature:

- **Text has no geometry.** `add_text` (`packages/core/src/commands/draw2d/annotate.ts`) is an annotation (content, cap height,
  anchor), not a profile: `extrude_profile` refuses it, there is no font, no outline, no area. The only lettering on a solid is
  `add_decal` (`commands/edit/decals.ts`): **paint**, from a built-in **5×7 block raster font** (`lib/blockFont.ts`, A–Z 0–9 and a few
  signs, lower case printed as capitals), projected along −normal, never part of STL / STEP.
- **Nothing maps a 2D sketch onto a cylinder, a cone or a freeform face.** Sketch planes are planar only (`create_sketch_plane`
  refuses a non-planar face); `project_edges_to_sketch` goes the other way (3D edges flattened into a plane); `split_face` cuts
  faces by a **plane** only; `trim_surface` projects curves onto a `nurbs_surface` sheet only.
- **But the exact machinery is already there**, built for 06 CMP composites: the developed chart of plane / cylinder / cone faces
  (`packages/domain-aero/src/composites/surface.ts` `toFlat` / `fromFlat`, isometric for those three) and the exact **`faceSlab`**
  recipe node (`model/faceSlab.ts`, native `face_slab` in `solver/crates/llull-kernel-occt/cpp/surfaces.cxx`): a (u, v) region of a
  plane / cylinder / cone / B-spline face lifted along its normal into a solid with walls normal to the face — which is exactly a
  wrapped emboss of one closed region.

This gap turns those pieces into the "design anything on a face" toolkit, CLI-first: wrap or project any 2D sketch or **outline-font
text** onto a face as exact curves on the surface, emboss / deboss / scribe it, split faces by those curves, unwrap a developable
face, put cosmetic knurls and wrapped patterns on cylinders, and always report the **numbers** an agent needs to prove the result:
lengths kept, distortion on doubly curved faces, region area, volume added or removed.

What "design anything" means here, distilled from the table: (1) **exact wrap on developable faces with wrap-around** (SOLIDWORKS
Analytical, Onshape), (2) **any-face wrap with an honest distortion number** (SOLIDWORKS Spline Surface, Rhino FlowAlongSrf hide
the stretch; llull reports it), (3) **outline and single-line fonts** as real profiles (Rhino TextObject; Fusion refuses single-line),
(4) **scribe / split** without material change, (5) **mould mode** (pull direction, draft), (6) **unroll** of developable faces with
the curves on them, (7) everything **parametric** (edit the text, the face regenerates).

## 4. Scope / out of scope

### 4.1 Phases

| Phase                                            | Content                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **MVP** (developable faces, exact; outline text) | Promote the developed chart to core; `wrap_to_face` (plane / cylinder / cone, isometric, wrap-around and seam crossing, anchor + angle + mirror); `project_to_face` (direction, closest point); `unwrap_face`; outline fonts: TrueType parser in core, bundled OFL font, `import_font`, `add_text font=…` as a closed profile (holes) accepted by `extrude_profile` and emboss, `text_outline` query; `emboss_on_face` emboss / deboss / scribe on plane / cylinder / cone with walls normal to the face (exact `faceSlab` path); `check_wrap`; stable codes; documents embed the font file. |
| **V1** (any face, mould, split)                  | Geodesic (exponential map) and parametric wraps on sphere, torus and B-spline faces with distortion report; emboss on those faces; `split_face_by_curves` (split line from projected / wrapped / on-face curves); pull-direction walls and draft; `create_curve_on_face` (geodesic, isoparametric, uv spline); CFF / OpenType-CFF fonts; kerning (GPOS / kern); multi-line text; `add_decal` font + wrap mapping; `add_knurl` cosmetic.                                                                                                                                                      |
| **V2**                                           | Single-line (engraving) fonts with tool-width engrave; multi-face wraps across tangent faces; text along a curve; `pattern_on_face` (wrapped grids); modeled knurl geometry (uses 02 SWG helical sweep); silhouette split; variable-font instances.                                                                                                                                                                                                                                                                                                                                          |

### 4.2 Out of scope

- Deforming whole bodies onto a curve or surface (bend, flow, CATIA Wrap Curve surface deformation): **01 DEF**.
- Mesh-only displacement / sculpted relief on scans: **07 MSH**.
- Image-based embossing (height map / lithophane from a PNG): COULD in 07 MSH; this pack does vector profiles only.
- Typesetting beyond one or a few lines (bidirectional text, complex-script shaping): out; Latin, Greek, Cyrillic, digits, symbols
  that map one character to one glyph are in scope; the shaping engine is an open question (D-WRP-6).
- Drawing-sheet text rendering (SVG `font-family` in `commands/drawings/sheetFrame.ts`) is unchanged.

## 6. Workflows

### 6.1 CLI (primary: the operator agent)

The complete job "raised brand name on a bottle, checked, rendered, exported", headless on a file:

```bash
llull search emboss wrap text                 # emboss_on_face, wrap_to_face, project_to_face, import_font, text_outline, check_wrap
llull describe emboss_on_face                 # params with units (depth in document units, angleDeg), modes, refusals
llull guide                                   # WRP section: chart axes per face kind, anchor + angle, minimal emboss plan
# 1. plan (validation/plans/target_cylinder_text_emboss.json):
#    set_units -> import_font (or the bundled default) -> add_cylinder -> add_text font=$fira -> text_outline
#    -> emboss_on_face (develop, anchor, depth 1) -> mass_properties -> check_wrap -> render_view
llull run bottle.plan.json --validate --doc bottle.llull.json
llull run bottle.plan.json --doc bottle.llull.json --json --progress
# 2. numbers, not pictures
llull text_outline id=$label --doc bottle.llull.json --json          # data.area 104.886, data.loops 5, data.advanceWidthMm
llull mass_properties entityId=$embossed --doc bottle.llull.json --json   # volume = 16000 pi + 107.508
# 3. closing check
llull check_wrap '{"ids":["$embossed"]}' --doc bottle.llull.json --json   # status, findings, limits (named defaults), unverified
# 4. look at it (multimodal agents)
llull render_view view=front isolate=$embossed --doc bottle.llull.json --save out/bottle.png
# 5. deliver
llull export_step --doc bottle.llull.json --save out/bottle.step
```

Variants, same loop: engrave (`mode: "deboss"`), split a paint region (`mode: "scribe"` or `split_face_by_curves` on curves from
`project_to_face`), unroll a cone label (`unwrap_face` then export the chart outline to DXF), a logo on a dome (`method:
"geodesic"`, read `data.distortion.maxLengthStrain`, keep it under the owner's limit). A change: `edit_step_params` on the
`add_text` step (content, height) or the emboss step (depth, anchor, angle); the history regenerates. `--dry-run` tries a mutating
command without writing (AF-42). Any refusal exits 1 with a stable code (TECHNICAL_SPEC §7.1).

### 6.2 UI (review surface)

The desktop app shows what the agent built (live with `--app`): wrapped curves drawn on the face, the emboss solid, a distortion
colour overlay on doubly curved faces built from `check_wrap` data (COULD), the knurl texture. Placing a wrap by dragging its anchor
on the face is a 04 DIR gesture that commits one `emboss_on_face` / `wrap_to_face` step on release. No capability depends on the UI.

## 8. Standards & conventions alignment

| Topic                | Alignment                                                                                                                                                                                                                                                                                                                                |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fonts                | OpenType 1.9.1 `glyf` (quadratic outlines, composite glyphs, overlap flags) [R19] and `OS/2` (`fsType` embedding permissions, `sCapHeight`) [R20]. `add_text.height` stays the **cap height** (today's meaning), converted with `sCapHeight`.                                                                                            |
| Font licences        | Bundled fonts are SIL OFL 1.1 [R24] [R25]; documents embed only fonts whose `fsType` allows it; the applicable rule is the font's own licence, which llull records (`licence`) and does not interpret.                                                                                                                                   |
| Developable surfaces | Plane, cylinder, cone have zero Gaussian curvature and an exact development (Rhino UnrollSrf requirement [R9]); everything else is approximated and reported.                                                                                                                                                                            |
| Knurling             | DIN 82 / ISO 13444 designations and pitch series are paywalled; a public Indian standard modelled on the same family (IS 3403:1981) was located but not read [R27]. llull stores the user's pitch and pattern and checks closure; it does **not** ship a standard pitch table until one is transcribed from a readable source (D-WRP-8). |
| Exchange             | Exact faces through the existing STEP path; DXF text outlines as LWPOLYLINE / SPLINE curves (TECHNICAL_SPEC §6).                                                                                                                                                                                                                         |

## 10. Risks & assumptions

| Risk / assumption                                                                                                                                                         | Impact                                             | Mitigation                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| The native OCCT build has **no FreeType** (`USE_FREETYPE` OFF in `solver/scripts/build-occt.mjs`), so OCCT's `Font_BRepFont` / `StdPrs_BRepFont` text-to-B-rep cannot run | No kernel-side text                                | Fonts are parsed in core (TypeScript, pure); outlines go to the kernel as exact 2D curves (TECHNICAL_SPEC §5.4, D-WRP-2)       |
| `faceSlab` loops are **polygons** in (u, v) and exactly **one outer loop** plus holes                                                                                     | Curved letters faceted; one slab per letter region | Extend the loop encoding with B-spline pcurve segments; one slab per outer loop, fused (TR-WRP-05)                             |
| Fonts with overlapping contours (variable-font instances)                                                                                                                 | Wrong area, bad solids                             | Nonzero fill: unite overlapping loops before the kernel (TR-WRP-07); the reference script checks overlap per glyph (VC-WRP-15) |
| Users import fonts they may not embed                                                                                                                                     | Licence breach in shared documents                 | `fsType` check refuses restricted fonts; unknown licence → `unverified` (FR-WRP-21, 44)                                        |
| Distortion on doubly curved faces is unavoidable                                                                                                                          | "Looks fine" results that stretch a logo by 10 %   | Distortion always in `data`, limit with a named default, `check_wrap` fails above it (FR-WRP-03, 40, 43)                       |
| Persistent face naming after upstream edits (SC-N1)                                                                                                                       | Emboss lands on the wrong face                     | Face picked by persistent name; lost name fails with `REF_LOST` (FR-WRP-16)                                                    |
