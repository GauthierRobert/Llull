# MSH — sources (accessed 2026-10-22)

Ids S1–S39 are the same documents as [R1]–[R39] in FUNCTIONAL_SPEC §11. Access method: **F** = page fetched and read (HTML),
**PDF** = PDF downloaded and its text extracted with the scratch Node tools (FlateDecode / LZW streams; no third-party code),
**L** = local file in this repository's installed dependencies, **API** = registry JSON. Vendor and reseller pages are product
descriptions: they support the benchmark table only, never a gating value.

Grades: **A** = primary source read, reference code run, or ≥ 2 independent sources agree; **B** = one secondary extract;
**C** = located, not confirmed. Only grade A values and closed forms gate pass / fail.

## Sources that could not be verified

- SOLIDWORKS official help (2018 What's New "Convert to Mesh Body", ScanTo3D topics): JavaScript-rendered, no text returned.
- CATIA (Digitized Shape Editor, Imagine & Shape), Siemens NX help, Creo Restyle, Onshape mesh handling: not fetched; no claim made.
- OpenMesh licence page (`graphics.rwth-aachen.de` refused the connection); Stanford 3D Scanning Repository terms
  (connection refused) — no Stanford model is used; large-mesh cases are synthetic.
- Qhull (`qhull.org` certificate mismatch): no Qhull fact is used; hull cases are closed forms.
- Liepa 2003 full text (encrypted PDF).
