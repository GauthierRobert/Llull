## Sources that could not be verified

- SOLIDWORKS help body text (fetch refused); only search extracts are used (grade B) — no SOLIDWORKS number gates a VC.
- OCCT tracker issue text (DNS failure from the sandbox); extracts only (grade C), used as risk evidence, never as values.
- The construction OCCT uses for a variable radius (sections normal to the spine vs the rolling-ball envelope): not stated in the
  headers read. VC-BLD-30 measures it (TECHNICAL_SPEC §11 Q2).
- The vendors' exact mapping of "rho", "C2 shape factor", "magnitude" and "form factor" to a cross-section curve: not published in
  the pages read. llull defines its own (TECHNICAL_SPEC §5.3) and claims no numeric equality with any vendor.
