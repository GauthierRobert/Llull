# IMP — Validation pack

Proves a future implementation of [FUNCTIONAL_SPEC.md](../FUNCTIONAL_SPEC.md) / [TECHNICAL_SPEC.md](../TECHNICAL_SPEC.md).
"Validated" = every grade-A `VC-IMP-*` below passes in an automated gate on the **TS field engine and the native `llull-field`
engine**, with the reference data of `data/` regenerated by the scripts of this folder.

## 4. Derivations not obvious from the scripts

- **Simple-cubic node overlap.** Three orthogonal cylinders of radius r and length a through the cell centre (each reaching the cell
  faces): union = 3·πr²a − 3·V₂ + V₃ with the bicylinder V₂ = 16r³/3 and the tricylinder V₃ = 8(2 − √2) r³ [S24]: 3πr²a − 16r³ +
  16r³ − 8√2 r³ = 3πr²a − 8√2 r³. Valid while each bicylinder lies inside the cell (r ≤ a/2) and parallel struts do not touch
  (2r < a). The cell of a periodic simple-cubic lattice holds exactly this volume whatever its origin, so the baseline plan (cylinders
  through the centre) and the target plan (nodes at the corners) give the same 82.93407 mm³.
- **Periodic node caps.** Every node of the four MVP cells lies on a strut that continues straight through it (the lattice is
  centrosymmetric about each node), so a ball of radius r at the node is contained in the union (a point within r of the node is
  within r of the line); "sphere" and "butt" caps differ only where a region clips struts.
- **TPMS 1/2.** Each map is volume preserving and sends F to −F, so {F < 0} and {F > 0} have equal volume and {F = 0} has measure 0:
  gyroid p → −p; Schwarz P p → p + (a/2)(1,1,1); diamond (short form) x → x + a/2; Neovius p → p + (a/2)(1,1,1). On a midpoint grid the
  P count is 0.5000182 at 240³: ties at points where F rounds to ±0 (≈ 250 of 1.38 × 10⁷ samples); the gate uses the exact 1/2.
- **Shell + infill.** The inner cube (side 3a, centred at the origin) is mapped to itself by p → −p, so the gyroid network fills
  exactly half of it; the skin (between the outer and inner cubes) is disjoint from the clipped infill.
- **Smooth corner.** See TECHNICAL_SPEC §5.3: added area 2∫₀^k (k − u)²/(4k) du = k²/6, times the 10 mm length.
- **Mesh error coefficient.** For the sphere the reference mesher's relative volume error is ≈ −0.50 (h/R)² (h = voxel); the gate
  uses 0.6 (h/R)², the rounded-up coefficient, not a fitted value of the implementation under test.

## 6. How an agent driver runs the pack

1. `node generate_expected.mjs` (or use the committed `expected_results.json`).
2. For each case with `grade: "A"` and a `gate`: run `cli.run` in a fresh temp directory, read `cli.assert` from `--json`, compare with
   `value` and `tolerance` / `tolerance_rel`; for `expectedCode` cases check exit code 1 and `error.code`.
3. Run each golden plan twice and once per engine (TS: `LLULL_NATIVE_DIR` unset; native: set) for VC-IMP-44.
4. Grade C cases are reported, never failed.
