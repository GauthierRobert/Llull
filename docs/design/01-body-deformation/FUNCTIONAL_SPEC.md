## 1. Summary

A deformation changes the shape of a whole body (or a region of it) by moving every point of space with one map: twist about an axis,
taper toward an axis, bend around an axis, stretch a region, scale differently along x, y and z, push a lattice cage, flow the
body along a curve or onto a surface, or push a point with a soft falloff. These are the tools designers use for the shapes that
are awkward to build from sketches: twisted bars and blades, flared handles, bent tubes and brackets, bulged bottles, ergonomic
grips, text and ribs wrapped around a drum, a straight part re-fitted along a curved path.

llull has **none of them** today (TECHNICAL_SPEC §1):

- `scale_entity` scales uniformly only; the `ShapeRecipe` has only a uniform `scale` node about the world origin; there is no
  non-uniform scale and no true mirror (`mirror_entity` moves the position and keeps the shape and handedness).
- There is no twist, taper, bend, stretch, lattice (FFD), flow or point deformation command, no recipe node for them, and neither
  kernel is asked to warp geometry (the Manifold `warp` / `warpBatch` API is not used; the native OCCT sidecar only applies
  `gp_Trsf` rigid placement and uniform scale).
- The only local deformation is `edit_subdivision_cage` (soft-selection move/scale of a Catmull-Clark cage), which works on
  subdivision solids only.
- An agent today can only approximate a twisted bar by lofting rotated sections: measured on the native kernel, the
  `baseline_twisted_bar_loft.json` plan gives a volume 0.041 % low and a surface area **1.93 % low** against the closed forms, because
  each section is resampled to 24 points and its corners are rounded (validation README §4).

This pack specifies the deformation family as registered commands for the CLI agent, an exact B-rep path (faces re-approximated as
B-splines within a stated tolerance, affine maps exact) and a mesh path, a numeric self-check (Jacobian, foldover, volume drift,
approximation error), and analytic validation data.

### 2.3 Value

- **Shapes from intent, not from re-sketching**: "twist this blade 35 degrees over its span", "taper the handle to 60 %", "bend the bar
  90 degrees on a 50 mm radius" are one command each, on any solid llull can build or import.
- **Parametric**: the angle, factor or radius stays a parameter of the feature history (L8); an agent sweeps a design space by
  editing it.
- **Agent-provable**: every deformation reports numbers an agent can check against closed forms (twist keeps volume exactly; a
  centred bend keeps volume by Pappus; a linear taper of a cylinder is an exact cone frustum), so the agent can prove its own work.
- **Downstream**: exact B-spline faces export to STEP like any other llull solid; mesh results feed 3D printing.

## 4. Scope / out of scope

### 4.1 Phases

| Phase   | Content                                                                                                                                                                                                                                                                                                                                                                               |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **MVP** | `scale_nonuniform` (exact affine), `twist_body`, `taper_body`, `stretch_body`, `bend_body` with the shared frame / region / falloff, both paths (exact B-rep re-approximation on the native kernel; refined-mesh warp on Manifold and without a kernel), validity (Jacobian, self-intersection), `analyze_deformation`, `check_deformation`, parametric replay, STEP of exact results |
| **V1**  | `deform_lattice` (FFD), `deform_by_point`, `flow_along_curve`, `flow_on_surface`; deformation of `nurbs_curve` and `nurbs_surface` entities; `preserveAnalytic` (recognise planes / cylinders / cones again); several bodies with one call; UI overlays for the frame, region and lattice                                                                                             |
| **V2**  | `deform_curve_to_curve` (SOLIDWORKS curve-to-curve, CATIA Wrap Curve, Creo Spine by reference), `morph_bodies` between compatible shapes, B-spline (non-Bernstein) lattices and oriented lattice boxes, local flow (tube of influence)                                                                                                                                                |

### 4.2 Out of scope

- Physical deformation (springback, FE displacement fields applied to geometry): 05 FEA results stay results.
- Sculpt brushes (grab, inflate, smooth, crease) on meshes: **07 MSH**. Drag gestures in the viewport: **04 DIR** (its gestures
  commit `deform_lattice` / `deform_by_point` from this pack).
- Wrapping 2D sketches, text and decals onto faces (length-preserving curve mapping): **03 WRP** (may reuse the flow map of
  FR-DEF-15 for curves).
- Twist and scale laws inside a sweep or loft: **02 SWG** (constructive; this pack deforms an existing body).
- Morphing between arbitrary topologies (signed-distance interpolation): **05 IMP**.
- 2D drafting entities (line, arc, polyline …): refused in MVP with a remediation (convert to `nurbs_curve` first); see D7.

## 6. Workflows

### 6.1 CLI (primary: the operator agent)

```bash
llull search twist bend deform                 # finds twist_body, bend_body, taper_body, deform_lattice, analyze_deformation ...
llull describe bend_body                       # units, the "any two of radius / angleDeg / length" rule, refusals
llull guide                                    # deformation section: frame, region, falloff, what each law preserves
# 1. plan (validation/plans/target_twist_box.json): add_box -> twist_body -> mass_properties -> analyze_deformation -> check_deformation
llull run twist.plan.json --validate --doc part.llull.json            # names step path + param on error
llull run twist.plan.json --doc part.llull.json --json                # ids, data, durationMs per step
# 2. numbers, not pictures
llull analyze_deformation id=$twisted --doc part.llull.json --json    # jacobian.min = 1, volume.predicted = volume.measured, approxError
llull check_deformation '{"ids":["$twisted"]}' --doc part.llull.json --json
# 3. look at it (multimodal agents)
llull render_view view=iso isolate=$twisted --doc part.llull.json --save out/twisted.png
# 4. iterate on intent
llull set_parameter name=twist expression=120 --doc part.llull.json   # history regenerates (L8), re-run step 2
# 5. deliver
llull export_step_ap242 --doc part.llull.json --save out/part.step
```

A refusal exits 1 with a stable code and a remediation, e.g. `DEF_BEND_RADIUS_TOO_SMALL at params.radius: the inner side is 5 mm
from the neutral fibre; use radius > 5 or move frame.origin toward the inner side`. `--dry-run` previews (FR-DEF-23).

### 6.2 UI (review surface)

The desktop app shows the result live with `--app`. The reviewer toggles the frame / region / lattice overlays and the Jacobian
map (FR-DEF-24), reads the `check_deformation` report, and approves a release through 09 PLM. The command dialogs come from
`listCommands()` like every command; no capability depends on them. 04 DIR adds drag handles whose release commits
`deform_lattice` / `deform_by_point` with the dragged values.

## 8. Standards & regulatory alignment

| Topic                   | Alignment                                                                                                                                                                                                               |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Terminology             | Twist, taper, bend, stretch as in Barr 1984 [R25] and the CAD tools of §2.1; FFD / lattice as in Sederberg & Parry [R26].                                                                                               |
| Geometry representation | Results are B-spline faces and edges (ISO 10303 STEP `B_SPLINE_SURFACE_WITH_KNOTS`, written by the existing AP242 path); no new exchange format.                                                                        |

## 10. Risks & assumptions

| Risk / assumption                                                                                            | Impact                                       | Mitigation                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------ | -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Re-approximating faces with B-splines can fail or exceed the tolerance on long, strongly deformed faces      | refusal or heavy faces                       | split faces at region ends and at knot-span count limits; report `DEF_APPROX_TOLERANCE` with the worst face; mesh fallback only when the caller allows (`mode: "auto"`) and then flagged |
| `BRepBuilderAPI_GTransform` converts every face to NURBS (except planes) even for a pure scale (OCCT source) | analytic faces lost on affine maps           | use `gp_Trsf` for similarities; `preserveAnalytic` recognition afterwards (FR-DEF-12)                                                                                                    |
| Manifold `warp` does not check overlaps                                                                      | an invalid mesh solid                        | injectivity check before (Jacobian bounds) and a self-intersection test after (FR-DEF-09)                                                                                                |
| A linear falloff leaves a crease at the region ends                                                          | unnoticed G1 break                           | default `smooth`; crease angle reported and warned (FR-DEF-06, 22)                                                                                                                       |
| SOLIDWORKS and NX help pages could not be fetched (JavaScript shells, login redirects)                       | benchmark rows rest on search extracts       | marked (SR); only grade-A closed forms gate tests                                                                                                                                        |
| Downstream features (fillets, holes) on a deformed body reference faces by name                              | broken references after a param edit         | the exact path keeps the topology 1:1 and maps persistent names (TECHNICAL_SPEC §5.6)                                                                                                    |
| The operator is an agent, the owner not an engineer                                                          | a folded or faceted body is reported as done | `check_deformation` ends every job; failures cannot be hidden; mesh results for release need review                                                                                      |
