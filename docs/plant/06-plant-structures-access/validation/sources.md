# Gap 06 STA — Sources

Accessed 2026-10-18. Network limits of the authoring sandbox: direct fetches of ecfr.gov, osha.gov, govinfo.gov,
law.cornell.edu, iso.org previews, manufacturer sites and docs.aveva.com / docs.cadmatic.com were refused (proxy 403 or
DNS failure in the fetch tool). Regulation and standard text was therefore read through search-engine extracts of the
pages listed below. raw.githubusercontent.com was reachable and supplied the downloaded files. Grades:

- **A**: primary text read (here: a search extract that quotes the regulation / standard page itself) **and** a second
  independent source agrees, or a closed form reproduces a published table.
- **B**: one secondary extract (vendor guide, blog, summary).
- **C**: located, value not confirmed or sources in conflict. Never used as a gate.

## Not reached / not verified (not used as gates)

- Full text of ISO 14122-2/3/4:2016 (paywalled; previews blocked). Hoop spacing (1000 vs 1500 mm), single-flight / rest-platform
  rule (6 m), toe-plate gap edition change (10 → 12 mm), guard-rail post spacing and the guard-rail test loads were not confirmed.
- eCFR / osha.gov pages could not be fetched directly; only extracts. The OSHA cage dimensional rules of the pre-2017 1910.27
  (cage start 7–8 ft, hoops 4 ft, bars 9.5 in) appear only in vendor extracts and are no longer in the current 1910.23/1910.29
  text; they are not loaded.
- API 2218 fire-scenario envelope dimensions (height above grade, radius); PIP STC01015 / STE03350 pipe-rack criteria (PIP is
  members-only). Both enter llull only as explicit, named project parameters.
- Metric grating load tables (RAL-GZ 638 / DIN 24537 series, EN ISO 14122-2 deflection limit): no table extract found.
- Smart 3D (Hexagon) handrail / ladder placement rules: no documentation extract found.
