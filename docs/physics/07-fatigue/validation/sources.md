All entries accessed **2026-10-15**. Spec citations `[Rn]` use the same number as `Sn` here.

**Access**: **git** = cloned through the session's git proxy, files read, commit pinned; **pypi** = wheel downloaded from
pypi.org and read; **search** = only web-search text was seen (WebFetch failed DNS for every host tried, and the
egress proxy refused `curl` to faa.gov, ecfr.gov, law.cornell.edu, ntrs.nasa.gov, arxiv.org, pmc/europepmc with 403);
**catalogue** = only the publisher's catalogue entry (title, edition, scope) is relied on.

**Grade** (README §6.3): **A** = ≥ 2 independent sources agree, or exact analytic derivation in the generator from a
formula that ≥ 2 sources state; **B** = one secondary source; **C** = source exists, value or wording not confirmed.
