# PHY-23 DRV — Validation plan

The pack follows one principle: **a physical-truth claim needs three independent legs**, so a defect in one leg cannot hide in
another.

1. **Analytic oracles.** [`generate_drv_reference.py`](generate_drv_reference.py) uses the Python standard library only and is run
   as `python3 -I`. Re-runs are byte-identical: sha256 `f0baa56b…15f24` (regenerated 2026-11-06 for the one-sided end stop, DRV-M1), checked twice with the bundled CPython
   `desktop/build/python/python.exe`. It writes [`drv_reference.json`](drv_reference.json), with closed-form solutions for the DC
   motor, thermal network, transmissions, friction, profiles, controllers and machines. The generator checks its own energy
   identities and symmetry conditions. [`expected_results.json`](expected_results.json) holds 88 pinned values in pack schema §6.3,
   built from that file by [`build_expected_results.py`](build_expected_results.py).
2. **A real datasheet.** maxon RE 40 148877 [R1] is internally consistent to 0.53 %. That makes it the shared test motor: real
   numbers, not invented ones.
3. **llull's own suites plus a second engine.** These are the unit, golden and server (`packReplay23`) suites, plus the V1 reference
   engine (TR-DRV-26). The reference engine shares the model with MuJoCo but none of its solver code.

Machine: the owner's Windows 11 workstation, reference for every timing. Grades are per [`../../README.md`](../../README.md) §6.3:

- **A**: exact analytic derivation or a primary source read.
- **B**: one secondary source, reported but not a gate.
- **target**: a behaviour or budget of this spec.

## Use cases

1. **UC-1 Datasheet motor.** Enter maxon 148877, check it, step it from rest, read current, speed, heat and energy (DRV-M1).
2. **UC-2 Servo axis sizing.** An indexing table on an S-curve: motor + gearhead N = 10 + friction. Run `size_drive` with a ratio
   sweep and `check_motion_truth` (M1–M3).
3. **UC-3 Lift that must hold.** A lead-screw lift: is it self-locking, how fast does it lift, does it fall with the power off (M2)?
4. **UC-4 Stick-slip.** A slide with stiction on a moving belt: is the limit cycle physically right (M2)?
5. **UC-5 Trust a result.** The PHY-22 slider-crank, driven by a 10⁶ N·m "motor", must not come out as `trusted` (M3).
6. **UC-6 Calibrate to the bench.** Fit friction from a measured spin-down (M3).
7. **UC-7 Other machines.** PMSM envelope with field weakening, stepper ringing and missed steps, induction torque–slip (M4).
8. **UC-8 Second opinion.** The reference engine agrees with MuJoCo on the pendulum, the double pendulum and Andrews (V1).
