# PHY-22 MOV — Validation plan

Reference mechanisms: the closed-loop slider-crank of PHY-10 (r 50 mm, l 200 mm, crank held at 100 rad/s by a speed motor, plan
copied as [`plans/mov_slider_crank_base.plan.json`](plans/mov_slider_crank_base.plan.json)), a box spinning about Z at π rad/s
([`plans/mov_clip_spin.plan.json`](plans/mov_clip_spin.plan.json)), and the golden plans `assembly_joints` and
`mechanism_four_bar_exploded` (`tests/golden/plans.ts`) for kinematic sweeps.

Machine: the owner's Windows 11 workstation (reference for every timing). Grades per [`../../README.md`](../../README.md) §6.3:
**A** exact analytic derivation in `generate_mov_reference.py` or measured in llull, **B** one secondary source, **C / target**
budget of this spec, not a measurement.

Validation layer (three independent legs, so a defect in one cannot hide in another):

1. **Analytic oracles**: [`generate_mov_reference.py`](generate_mov_reference.py) (Python stdlib, `python3 -I`, byte-identical
   re-run; checked 2026-11-02 with the bundled CPython: sha256 `9484de5c…b187` twice) writes [`mov_reference.json`](mov_reference.json):
   frame timeline, slider-crank piston x(t), spin-clip centre, GIF delay schedules.
2. **Container oracle**: [`check_media.py`](check_media.py) (Python stdlib) parses APNG / GIF / MP4 structure (chunk CRCs, APNG
   sequence numbers and acTL-before-IDAT per PNG-3 [R6], GIF blocks, delays and NETSCAPE loop, MP4 box tree, sample count,
   timescale, codec configuration box). It shares no code with llull's encoders. Self-tested 2026-11-02 on a llull PNG, a
   synthetic 3-frame APNG, a 2-frame GIF and a truncated GIF (rejected); its MP4 branch ran on a real AV1 file in MOV-M0 (spike, [`playback.md`](playback.md)) and is
   first exercised by VC-MOV-10 in MOV-M2 (if it disagrees with `ffprobe` on that file, fix the checker before trusting either).
3. **llull's own suites**: unit / golden / server / native / component tests listed per VC (TECHNICAL_SPEC §9), plus the
   human playback check of VC-MOV-10.

## Use cases

1. **UC-1 Show a simulated cycle.** Slow-motion MP4 of the slider-crank with trace and readouts (MOV-M1, M2).
2. **UC-2 Agent review loop.** Contact sheet → fix camera / overlays → encode (MOV-M1, M3).
3. **UC-3 Kinematic sweep.** Four-bar driven through its range, there and back (MOV-M1).
4. **UC-4 Clips without a screen.** Render `animate` clips from the CLI exactly as the viewport plays them (MOV-M1).
5. **UC-5 Owner export.** Desktop "Export animation…" to an MP4 that plays on the owner's PC (MOV-M4).
