# KRN — external sources

All accessed **2026-10-15**. Network note for this session: the egress proxy refused `dev.opencascade.org`,
`wiki.freecad.org`, `nist.gov`, `mbx-if.org`, `iso.org`, `airbus.com`, `nasa.gov` and most other sites
(CONNECT 403); `raw.githubusercontent.com`, public `git` over HTTPS, `pypi.org` and `registry.npmjs.org` were
reachable. The **Method** column says how each source was verified:

- **fetched** — the document itself was downloaded and read (quoted facts were checked in the text);
- **git** — read from a public repository at a pinned commit / tag;
- **api** — package-registry metadata (PyPI / npm JSON API);
- **search** — only the web-search result summary of the page was available (page could not be fetched);
  such sources support context and dates only, never an expected value;
- **measured** — produced by a script in this folder with OCCT 7.9.3 (OCP wheel `cadquery-ocp 7.9.3.1.1`).
