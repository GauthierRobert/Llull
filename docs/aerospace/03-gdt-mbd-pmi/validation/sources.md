# GDT — external sources (access date 2026-10-15)

How each source was accessed in this session:
- **fetched**: the page/file itself was retrieved (WebFetch on github.com, or `curl` of raw/LFS files with sha256 recorded).
- **search**: direct fetch of the host failed (DNS resolution failure from the fetch tool for nist.gov,
  nvlpubs.nist.gov, tsapps.nist.gov, pages.nist.gov, iso.org, asme.org, mbx-if.org, dev.opencascade.org,
  web3d.org, wikipedia.org, data.gov); the fact was verified from the search engine's retrieval of that
  exact URL (title + extracted text). Facts marked "search" should be re-checked by a human with a browser
  before external publication.
- The session's web-search budget ran out before tolerance-analysis textbooks and more vendor pages could
  be searched; the stack-up formulas are therefore derived in-repo (scripts) rather than quoted.

## Sources that could not be verified in this session

- Direct reading of nist.gov / nvlpubs PDFs (AMS 100-10 tables of PMI per test case, GCR 15-997 results):
  host unreachable from the fetch tool; only search-engine retrievals used.
- NIST open-licence text (https://www.nist.gov/open/license): not fetched → NIST files are pinned, not committed.
- Clause content of ASME Y14.5-2018, Y14.41-2019, ISO 1101/5459/14405/2768/16792/21920, ASME B46.1 — paywalled; not used.
- Whether ASME Y14.5-2018 still includes concentricity and symmetry — not verified; handled as rule-table data (FUNCTIONAL §8).
- Boeing 787 MBD adoption claims: a targeted search found no authoritative source; not used.
- Airbus supplier MBD requirements: not found; only the A350 maintenance-data statement (R25) is cited.
- MIL-STD-31000C existence: vendor blog only.
- Tolerance-analysis references (textbook RSS/Monte Carlo treatments): web-search budget exhausted;
  formulas derived in `generate_stackup_reference.py` instead (probability theory: variance of a sum of
  independent variables; Irwin–Hall CDF).
