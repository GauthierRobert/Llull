# Gap 13 FLT — Validation pack

Proves the flight model. Every expected value is (a) quoted from a fetched source, (b) a closed form of a cited model with
the derivation shown, or (c) `TBD — measure with <tool>`. **No value was produced by running llull.** Derivations were
computed with a plain Node.js script from the inputs listed here (2026-11-02).

## Gate policy

Same as 10 AER: grade **A** values and closed forms are pass / fail thresholds; grade **B** values are context or inputs;
grade **C** values are never thresholds. The UIUC coefficients are grade A for the rotor-law cases because they are read
verbatim from the published data files ([S1], [S2]) and the law under test is the definition the UIUC data uses
(T = CT·ρ·n²·D⁴, P = CP·ρ·n³·D⁵, n in rev/s).
