# Sources — gap MAT (materials & standard parts)

All sources accessed **2026-10-15**.

**How sources were verified.** In the authoring sandbox, direct page fetches failed: `WebFetch` returned DNS
errors (`ENOTFOUND`) for every host tried (everyspec.com, faa.gov, ntrs.nasa.gov, wikipedia.org), and `curl`
got proxy `403` on CONNECT. Verification used the **web-search index content** of each page. "Verified" below
means the quoted fact appeared in that page's indexed content. Facts that came only from a search *summary*
without a page excerpt, or only from forums or calculators, are marked **secondary**. The session's web
search budget ran out before every material could be covered, and the gaps are listed at the end.

**Action for the implementer.** Before any value from this folder ships in llull's seed library
(TECHNICAL_SPEC §6.3), re-verify it against the primary document (MIL-HDBK-5J PDF, AC 43.13-1B PDF, NAS sheet
under licence). Record a sha256 of the primary PDF in `sources.lock.json` (TR-MAT-41).
