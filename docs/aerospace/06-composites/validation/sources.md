hosts were blocked: DNS failures in WebFetch, and HTTP 403 from the sandbox egress proxy for curl. Only
`raw.githubusercontent.com` could be reached. Every source below was therefore checked through **web-search
result excerpts** (search engine snippets and summaries of the page text) on 2026-10-15. Where an excerpt did
not show a number, the number is **not** used as "quoted". It is either derived (and the derivation is shown)
or marked TBD. Paywalled standards: only the catalogue facts (title, edition, scope) are stated.
